VPX ScoreTracker

VPX ScoreTracker saves your Visual Pinball X scores locally, with a desktop Viewer for browsing your tables and game history.

Score tracking is made possible by Tom Logic’s pinball-memory-maps project, while VPX integration follows the example provided by jsm174/vpx-sample-plugin.

Install

Install Plugin

  1. Close Visual Pinball X.
  2. Extract the scoretracker/ folder from the plugin ZIP into your VPX plugins directory.
  3. Enable ScoreTracker in VPX settings, or add the following to VPinballX.ini:
[Plugin.ScoreTracker]
Enable = 1
Notifications = 1
macOS
Your VPX app/Contents/PlugIns/scoretracker/
Linux
plugins/scoretracker/ inside your VPX installation.

Install Viewer

  1. Extract the entire Viewer ZIP.
  2. On macOS, open ScoreTracker.app. On Linux, open ScoreTracker/scoretracker-viewer.
  3. Choose your tables folder. Select your VPX installation to read the table high scores from NVRAM.
